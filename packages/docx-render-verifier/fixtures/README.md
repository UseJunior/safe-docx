# Public renderer-verifier fixtures

All fixtures in this directory are synthetic OOXML fragments or generated from
synthetic text. They contain no client matter material. `index.json` maps each
minimal shape to a test purpose; `PROVENANCE.md` records the redistribution
status and the leak scan command.

These fixtures are deliberately render-oriented: they demonstrate only the
smallest body/header/table/comment shapes needed to exercise renderer and
corpus plumbing. They are not legal-document templates.

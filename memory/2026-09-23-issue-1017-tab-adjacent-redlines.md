# DEBUG REPORT — issue #1017 (2026-09-23)

- **Symptom:** Changing one word in a `w:r` with `w:t`, `w:tab`, `w:t` produced whole-text-child delete/insert wrappers, so the independent release verifier counted preserved words and punctuation as lost.
- **Root cause:** `simpleTextRun` rejects a run containing `w:tab`; the run-pair fallback in `refineRunReplacement` then wraps each changed `w:t` whole. A temporary instrumented reproduction confirmed the fallback is reached before `refineSimpleRunGap`.
- **Fix:** For matching runs with identical direct formatting, unchanged tabs, and only text/tab children, refine each changed nonempty text child through the existing token alignment helper on a tab-free fragment. Emit each tab once as common structural content. Other auxiliary children, changed tab XML, and formatting changes retain the prior behavior. Repeated words follow the helper's established deterministic alignment rather than triggering a new coarse fallback.
- **Evidence:** The synthetic regression failed before the change with `w:delText` equal to the entire `Section 1. Purchase price is one hundred dollars` child. After the change, it deletes only `one`, inserts only `two`, preserves exactly one tab, and accept/reject visible characters equal the respective inputs. The independent verifier reports `passed: true`, zero lexical, punctuation, and structural loss. An isolated `npm ci --ignore-scripts` and `npm run build` succeeded. The full repository `npm run test:run` passed under normal local IPC and LibreOffice permissions (including comparator 694/694, docx-core 1405 passed/1 skipped, release verifier 58/58, and render verifier 65/65). The first sandboxed run's tsx IPC and LibreOffice permission failures were reproduced as environment-only by passing focused reruns with normal permissions.
- **Regression tests:** `packages/docx-compare/src/tagged/pipeline-tab-adjacent-refinement.test.ts` and `packages/docx-release-verifier/src/minimality.test.ts`. Controls cover leading/consecutive tabs, repeated common words, cross-tab movement, and incompatible direct formatting.
- **Related:** #846 tracks broader dense alignments; #998 is the umbrella. This fix does not claim to resolve all dense-alignment cases.
- **Status:** DONE_WITH_CONCERNS pending PR merge and exact-merge smoke; local regression, peer-review, and pre-submit test requirements passed.
